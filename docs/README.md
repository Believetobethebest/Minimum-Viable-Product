# My Project Goal
My project keeps track of how much time you put in for your warm up routine in dance practice from a warm up log.

## The Problem
What I am trying to solve is making enough time for Bharatanatyam dance practice, specifically how many hours per week did you do it. For that to happen, I must make sure to stretch and warm up correctly before I start dancing. Occasionally, my legs tend to hurt while sitting in a half or full squat position as well as while lifting my legs up.

## Description
My project first captures user inputs from the terminal. Second, I package my code in a separate JAR file. My program uses File I/O to write a file which logs your warm routines and the amount of time you put in for each week. It also includes dedicated command-line interface frameworks, like Picoli and JCommander.
